## Decisions
- `Connector` protocol lives in `SupplCore/Contracts.swift` (Foundation-only) instead of the app layer, so the app and tests share one definition.
- Engine signature is `plan(plans:statuses:signals:history:prefs:now:calendar:)`. It always plans today and tomorrow from `now`, so there is no separate `day:` argument. `history` (decisions already delivered) is added so a post-workout reminder that already fired is never sent twice.
- `Slot` gains a `postWorkout` case. Existing raw values are unchanged.
- `Supplement` gains `uid`, `frequencyRaw`, `weekdaysRaw`, `clinicianDirected`, `notes`, `catalogID`, all defaulted. `uid` is optional and backfilled at launch, because a non-optional default would give every existing row the same id.
- `profile.isAdult` defaults to true: everyone who onboarded before v1 passed the 18+ toggle.
- `Suppl/Info.plist` is generated by XcodeGen from `project.yml` (needed for URL scheme, BG task ids, WHOOP keys). It pins `CFBundleShortVersionString`/`CFBundleVersion` to `$(MARKETING_VERSION)`/`$(CURRENT_PROJECT_VERSION)` so `scripts/testflight.sh` build bumps keep working.
- Test target does not link SupplCore a second time; the hosted test bundle resolves it through the app.
- Subagents commit in local worktrees and never push, so Zach's repo gets no extra branches.

- Merge order was C, A, B, D (not A, B, C, D): C finished first and the file sets were disjoint, so merging early started the macOS compile loop sooner.
- Agent worktrees were created from `main`, so each agent reset its empty worktree onto the feature branch before starting. Nothing was lost.

### Engine (agent A)
- `planIDs` keep the app's input order so notification text follows the user's list.
- Snooze applies to the whole group (latest `until` wins). A snooze landing in quiet hours moves to the quiet end only if still inside the window, otherwise it's dropped (a bedtime dose never moves to morning).
- A stale workout falls back with plain usual-time wording; "No workout recorded today" only appears when a workout source is connected and Pro is on.
- Same workout from two sources: the earliest-ending report wins.
- Late wake: the shifted wake/breakfast reminder fires at the wake time (or now + 60 s if already past), clamped to the window.
- Calendar: gap search starts at the later of window start and now + 60 s; the earliest gap can be before the usual time. Groups with a clinician-directed plan are never moved.
- Quiet hours: start == end means none. The bedtime exemption covers the initial reminder only; with defaults the bedtime follow-up (22:30) lands at quiet start and is dropped.
- DST: a skipped 2:30 AM resolves to 3:00 AM; a repeated time uses its first occurrence.
- The 48 cap can't be reached with 6 moments x 2 days (max 36); it's tested through an internal helper.
- Spacing rules (calcium/iron, zinc/iron, zinc/magnesium) ship `enabled: false`. Two informational notes are enabled. The engine never moves doses for spacing in v1.

### Catalog and content (agent B)
- 66 catalog entries, 44 tips. All 74 source URLs fetched (200) and checked against page titles. Sources: ODS, NCCIH, FDA, MedlinePlus, NEI, NIA.
- `examineURL` is null everywhere: examine.com bot-blocks the VPS (HTTP 429). Links can be added by someone with a browser.
- `withFoodHint` is "food" only for vitamins A, D, E, K, D3+K2, multivitamin; everything else "unknown".
- NAC and apple cider vinegar left out (no NIH/FDA page). Collagen and L-theanine cite general supplement-safety pages only.
- `bestMatch` returns nil for names that mention two ingredients or ambiguous typos.
- Zach's 7 tips kept word for word with sources, except the snooze tip, rewritten for configurable intensity.

### Connectors (agent C)
- WHOOP docs verified: OAuth URLs, 8-char state, scopes, v2 paths, `nextToken`, rotating refresh tokens. Rate limits are 100/min and 10,000/day with `X-RateLimit-Reset`; the app also honours `Retry-After` and otherwise backs off up to 1 h. Disconnect calls `DELETE /developer/v2/user/access`.
- Keychain tokens survive app deletion, so a fresh install deletes them (only when protected data is available).
- A refresh that returns 400 signs WHOOP out and asks the user to connect again.
- Optional `x-suppl-key` header from `WHOOP_APP_KEY` (empty by default).

### Integration (orchestrator)
- "Taken" for the engine follows `lastTakenAt` (set by Home and by the notification), so un-marking on Home always wins. Skip/snooze come from `DoseLog`.
- Each scheduled reminder is recorded in `DecisionLog` when scheduled; once its fire date passes it counts as delivered history. Removed-before-firing entries are deleted.
- Connector signals are cached for 5 minutes between runs so routine edits don't hit WHOOP's rate limit; HealthKit/calendar change events force a refetch.
- Triggers use `UNTimeIntervalNotificationTrigger` (absolute time); time zone and clock changes re-plan.
- `Reminders.scheduleFollowUp`, `markTaken(slot:)`, `names(in:)` removed: the engine and `ReminderActions` replace them. Category and action ids are unchanged.

### Phase 4 review (fresh agent, did not write the code)
Fixed:
- **Blocker:** reminders stopped after two days if the app was never opened (one-shot triggers for today and tomorrow only; main repeated forever). Engine now plans initial reminders 7 days ahead (`Preferences.planningDays`), follow-ups for 2 days.
- **Blocker:** overlapping scheduler runs returned early, so a Taken could leave a follow-up pending when iOS suspended the app, and a forced connector refresh could be lost. `run()` now waits for a run that started after the call; actions also remove the group's follow-ups immediately.
- DecisionLog written only when `UNUserNotificationCenter.add` succeeds; onboarding re-plans after permission and on finish.
- Taken tapped after midnight on yesterday's reminder no longer marks today.
- Post-workout fallback copy no longer claims "No workout recorded today" hours after planning.
- Calendar (wall-clock) triggers instead of time-interval triggers, so reminders follow local time while travelling.
- Free users with connected apps get an accurate status line (smart timing is Pro) instead of "hasn't updated".
- Apple Health shows "Set up" (iOS hides read authorization).
- Paywall "slept in" claim softened to what can actually happen; full auto-renew disclosure added.
- Billing retry (outside grace period) no longer grants Pro; Pro changes re-plan immediately.
- Test reminder respects privacy mode and its actions record nothing.
- No "Still open" follow-up for an initial that was never sent. BG task reports failure on expiry.
- Added an on-disk upgrade test (pre-v1 store opened with the v1 schema).

Accepted, not changed:
- A snooze that lands in quiet hours is dropped if quiet hours end after the window (so a bedtime dose never moves to morning). Conservative; Zach may prefer moving it.
- A clinician-directed post-workout plan is still timed from the workout: "after a workout" is the instruction itself.
- Typed names are linked to a catalog entry by `bestMatch` (cautious: nil on ambiguity). Only general notes and informational rules depend on it; spacing rules are disabled.
- WHOOP broker has no PKCE or rate limit. Acceptable for a 10-member dev app; revisit before WHOOP approval.
- Late-wake shifting only helps when the app learns the wake time before the reminder fires (no sleep observer yet).
